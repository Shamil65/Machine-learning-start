# ML Study

Реализация алгоритмов ML с нуля и практика на реальных данных.
Цель — подготовка к стажировке в Machine Learning.

## Структура

- ml_from_scratch/   — алгоритмы реализованные вручную без sklearn
- kaggle/            — проекты на реальных датасетах

## Реализовано с нуля

- Линейная регрессия (SGD, L1/L2/ElasticNet, mini-batch)
- Логистическая регрессия

## Kaggle проекты

- **Diabetes** — предсказание прогрессирования диабета,
  линейная регрессия, R² = 0.XX
- **Breast Cancer** — классификация опухолей,
  логистическая регрессия, accuracy = 0.XX

## Подход

### ml_from_scratch
Алгоритмы реализованы вручную без использования sklearn.
Цель — глубокое понимание математики и механики каждого алгоритма.
Каждый файл содержит реализацию класса и тесты на реальных датасетах.

### kaggle
Проекты на реальных данных с использованием стандартных библиотек
(sklearn, XGBoost, LightGBM). Цель — качество предсказания и
практика работы с данными: EDA, feature engineering, подбор модели.
